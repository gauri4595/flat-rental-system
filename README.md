# Flat Rental System

A console-based Java application for managing flat rentals. Flats are stored in a Binary Search Tree keyed by rent, with separate Admin and Customer portals.

## Features

**Admin portal**
- Login with forgot-password option
- Add, remove and view flats
- View customer details
- Update rent

**Customer portal**
- View all available flats
- Search by area, price or category (1BHK / 2BHK / RK)
- Book a flat
- Leave a flat and rate it

## Tech
- Java
- Binary Search Tree

## How to run
javac miniproject.java
java miniproject.miniproject
